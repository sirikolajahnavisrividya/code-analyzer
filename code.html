import sqlite3
import logging
from flask import request

logger = logging.getLogger(__name__)

def get_user_profile(user_id: str) -> list:
    conn = sqlite3.connect("users.db")
    cursor = conn.cursor()

    # Hardened: Parameterized Prepared Statement (Prevents SQLi)
    query = "SELECT * FROM users WHERE id = ?"
    cursor.execute(query, (user_id,))
    result = cursor.fetchall()
    

    # Optimized: O(n) Ordered Deduplication with dict.fromkeys()
    try:
        return list(dict.fromkeys(item for row in result for item in row))
    except (sqlite3.Error, TypeError) as err:
        logger.error("Profile extraction fault: %s", err)
        return []

3 Deep-Dive Modules Available

When an application constructs SQL queries using raw string concatenation (such as query = "SELECT ... " + user_input), an attacker can inject malicious syntax like ' OR '1'='1' --. This rewrites the query logic, granting unauthorized access to private data.

The Fix: Prepared statements separate the SQL code structure from untrusted user data. The database compiles the query schema first, then binds the arguments strictly as raw literals, preventing execution of injected commands.

In your original code, running if item not in processed: scans the entire processed array from beginning to end for each of the nested rows. If your database table returns 10,000 items, this triggers up to 100,000,000 comparison operations.

The Solution: Python's hash tables (such as set() or dict.fromkeys()) provide O(1) amortized constant lookup. The total operation drops down from 100,000,000 steps to just 10,000 steps, cutting response times from seconds to sub-milliseconds.

Using a bare except: block swallows all errors indiscriminately. It intercepts memory overflows, OS interrupt signals, and logic typos without generating a stack trace or log entry.

Best Practice: Always capture explicit, domain-specific exception types (e.g., except sqlite3.DatabaseError:), emit a telemetry event to your observability collector, and guarantee safe fallback defaults.
